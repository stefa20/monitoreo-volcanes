# Boletín de Volcanes de Lodo

Geoportal web para la visualización de cambios
en la superficie obtenidos mediante procesamiento
InSAR de datos SAOCOM.

## Procesamiento

SAOCOM → ISCE → MintPy → GeoTIFF

## Portal

- Leaflet
- GeoTIFF
- GeoJSON
- Chart.js
- GitHub Pages

## Estado

Versión inicial con el volcán de lodo El Aburrido.
